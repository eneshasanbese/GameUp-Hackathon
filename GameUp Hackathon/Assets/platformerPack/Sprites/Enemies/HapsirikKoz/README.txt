HAPSiRiK KOZ - UNITY SPRITE PACKAGE

128 x 128 pixels per frame; 128 Pixels Per Unit.
Idle: 8 frames, suggested 8 fps, loop enabled.
Sneeze: 12 frames, suggested 12 fps, loop disabled.
Sneeze impact: frame 05 (zero-based). No fire-wave VFX included.

Drag the HapsirikKoz folder into your Unity Assets folder, keeping each PNG beside its .meta file. The two sheets have Multiple mode and predefined slices. Expand Idle.png / Sneeze.png and use frames in numeric order to create animation clips. Animation clips and an Animator Controller are NOT included.
If your Unity version does not retain the slicing metadata: Sprite (2D and UI), Multiple, PPU 128, Sprite Editor > Slice > Grid by Cell Size > 128 x 128. Read left to right, then top to bottom. Use a common pivot (0.5, 0.1015625). Filter Bilinear, no mipmaps, compression None.

Frames/ also contains separate transparent PNGs. Their import settings are not preconfigured; use the sheets for the predefined import configuration.

These are source-image-based 2D deformations and facial edits, not independently redrawn animation cels. Preview in the intended camera scale and adjust timings before production use. Metadata must be checked in your Unity version; this package was not tested inside Unity.
